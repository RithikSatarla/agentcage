How you use it

Step 1

Install it

One dependency. No account, no key, no service to run.

pip install -e ".[dev]"
Step 2

Point your agent at it

Swap the recorded mock for AgentCage. Your agent code does not change.

- client = httpx.Client(
-     transport=RecordedMock())
+ cage = Interceptor()
+ client = httpx.Client(
+     event_hooks=cage.httpx_event_hooks())
Step 3

Push the PR

Your existing workflow runs it. Nothing else to wire up.

- run: pytest tests/
  git push origin fix/refunds

Step 4 · run it

Same test. Two answers.

Your agent retries a refund. Flip the switch to see the same test with and without AgentCage.

vs
tests/test_refunds.py
$ pytest
What’s happening

    Why the recorded mock missed it

    1

    It has no memory

    A recording answers the second refund exactly like the first, because it was captured once and never updated.

    POST /v1/refunds → 200 · every time
    2

    AgentCage keeps state

    The first refund changes the order. The second one meets that change and gets the error the real API sends.

    POST /v1/refunds → 400 charge_already_refunded
    3

    It never touches traffic

    Capture is passive. A test asserts your agent gets the reply back byte for byte, with API keys stripped from the trace.

    traces/example_double_refund.json · 4 requests
