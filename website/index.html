What’s happening

    What just happened

    1

    Watch

    AgentCage attaches to the HTTP client your agent already uses. It records every request and never alters one — a test asserts the reply comes back byte for byte.

    client = httpx.Client(event_hooks=cage.httpx_event_hooks())
    2

    Apply

    A refund is not a recorded reply. It changes the order, and every later read sees the change — the way the real API behaves.

    POST /v1/refunds → 200 · refunded 0 → 5000
    3

    Refuse

    The second attempt meets the state the first one left behind, and gets the error the real API would send — same status, same code, same message.

    POST /v1/refunds → 400 charge_already_refunded
    4

    Prove

    Every attempt is written to a trace with API keys stripped out, so it is safe to commit. This exact run is in the repo, and a test checks it still holds.

    traces/example_double_refund.json · 4 requests, 3 writes
