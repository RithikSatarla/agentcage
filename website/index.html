What’s happening

    Three lines in your tests

    Point your agent's HTTP client at AgentCage instead of a recorded response. Nothing else changes — same client, same code, same tests.

    It watches without touching: every write your agent attempts is recorded, with API keys stripped out, so you can read exactly what it tried to do.

    What it models 
    from part_b.stripe_mock import StripeMock

stripe = StripeMock()
charge = stripe.post_charge(amount=5000)

stripe.post_refund(charge=charge.id, amount=5000)
stripe.post_refund(charge=charge.id, amount=5000)
# StripeError: already refunded (400)

    We checked whether anyone tests this

    We read 45 open-source AI agent projects and found every tool that can change something real — pay, delete, push, send.

    One in five is never tested

    And the bar was as low as it goes: a tool counts as tested if its name shows up anywhere in the test files. It doesn't have to run.

    The riskiest ones are the worst

    Tools that push code and run shell commands are the least tested of all — the ones that can do the most damage.
