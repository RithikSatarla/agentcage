What happened when we ran it

We pointed three real open-source agent tools at the model, with their own code unchanged. Every one of their test suites passes. Every one of them got a write wrong.

  1. camel-ai/camelGithubToolkit

    Reads a file from the default branch, then writes that version to a different branch. GitHub rejects it. The error is never caught.

    Its 9 tests pass — with the entire GitHub library replaced by a mock that always says yes.

  2. agno-agi/agnoJiraTools

    One call to create an issue. Two issues created. The tool reports a single success and never sees the duplicate.

    The retry happens inside the HTTP client, below the tool.

  3. run-llama/llama_indexJiraIssueToolSpec

    Same shape, different project. One call, two issues, one reported success.

    Written independently of agno, and wrong the same way.

Three agents is a small number, and the models were built against these clients, so the clean parts of the result say more about fit than about generality. The limitations are written down in full, alongside every request each agent made. Read the protocol.

20.3% of write-capable agent tools have zero test coverage.

That’s 32 of 158 tools across 13 open-source projects with real API access and no safety tests.
